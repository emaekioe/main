# Backend-Semesterprojekt-UNO
Entwicklung einer Plattform für Bildungsspiele vom Typ „UNO”

Für jede Story wird ein seperater Branch angelegt, der die Storynummer im Namen beinhaltet.

Nach erfolgreichem Testen einer Komponenente/Feature wird der Branch in den Main gemerged.

Bitte lokal SonarQube installieren, um eine höhere Codequalität zu erreichen.
